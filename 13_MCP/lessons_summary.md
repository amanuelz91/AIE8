# Lessons from OpenAI Responses API - File Search and MCP Servers

## Lessons Learned

• Vector stores enable semantic search across documents with automatic citations
• MCP connectors require OAuth tokens for external services like Google Calendar
• File processing is asynchronous; wait for "completed" status before searching

## Lessons Yet to Learn

• Error handling strategies when MCP servers fail or return unexpected data
• Production deployment considerations: rate limits, caching, and cost optimization
• Advanced MCP tool permissions and approval workflows for sensitive operations
